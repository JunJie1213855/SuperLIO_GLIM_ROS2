# 运动补偿多帧重定位方案

日期：2026-10-28。核心流程已按本方案实施；运行配置及当前边界见 [使用说明](motion_compensated_relocalization_runtime.md)。
地图特征缓存、动态 IMU 冷启动、运行中自动失锁恢复及动态换图版本管理仍为后续工作；当前采用单地图会话和先验代号。

## 1. 目标与坐标约定

先在局部坐标系 S 中运行完整的 SuperLIO，再用运动补偿后的局部点云与世界地图 W 配准。
成功后将当前 ESKF 及后续地图观测统一切换到 W。

- `W`：已有 PCD 地图的固定坐标系。
- `S`：本次局部 LIO 会话的固定坐标系，配准期间不随滑窗移动。
- `I_k`：第 k 帧扫描结束时的 IMU 坐标系。
- `P_k`：去畸变后、已经应用雷达到 IMU 外参、表达在 `I_k` 中的点云。
- `T_S_Ik`：局部 ESKF 在该帧观测更新后的 IMU 位姿。
- `T_reg = T_W_S`：将源局部点云 S 变换到目标地图 W 的完整刚体变换。

因此：

```text
M_S = union_k(T_S_Ik * P_k)
M_W approximately equals T_W_S * M_S
T_W_Ilatest = T_W_S * T_S_Ilatest
```

`P_k` 对应现有 `scan_undistort_full_`，累积时不要再次应用雷达到 IMU 外参。
若使用原始雷达点，必须先做逐点去畸变和一次外参变换。

## 2. 状态机和地图所有权

```text
LOAD_REFERENCE_MAP
  -> INITIALIZE_LOCAL_IMU
  -> SEED_LOCAL_MAP
  -> LOCAL_TRACKING_AND_ACCUMULATION
       -> 异步提交局部点云快照 -> 配准工作线程
       -> 失败：继续局部跟踪，刷新窗口后重试
       -> 成功：返回 T_W_S 和质量结果
  -> COMMIT_AT_SCAN_BOUNDARY
  -> WORLD_MAP_TRACKING
```

管理两套地图，禁止初始化前混用：

| 数据 | 坐标系 | 用途 |
| --- | --- | --- |
| `local_ivox` | S | 为局部 ESKF 提供点面观测，允许更新 |
| `reference_cloud` | W | 已有地图的不可变配准目标 |
| `reference_ivox` | W | 重定位成功后为 ESKF 提供地图观测 |
| `relocation_window` | S / 各帧 I_k | 保存短窗口点云及对应的局部位姿 |

已有地图加载和索引构建失败时留在失败状态，不打印成功，也不以空地图继续配准。
地图可以在初始化阶段预先建立 W 系索引；本地跟踪的活动地图仍必须是 S 系索引。

### 局部初始化边界

本方案支持可靠局部 LIO 建立后的运动累积，不把运动期间的平均加速度直接当作纯重力，
也不把运动期间的平均角速度直接当作陀螺零偏。

首版可使用已有可靠的 IMU 标定/初值，或用静止检测完成短时 IMU 初始化，再允许运动。
若要求从上电起持续运动的冷启动，动态 IMU 初始化应作为单独工作项，不能宣称本改造自动解决。

局部种子地图只用首帧经 IMU 处理的点云，后续每帧必须进行预测、去畸变和地图观测。
不能直接复用当前 `SuperLIO::map_init()` 中按同一初始位姿插入多帧原始点云的逻辑。

## 3. 每帧处理与累积

每个有效扫描执行：

```text
LiDAR/IMU 同步
  -> IMU 传播与逐点去畸变
  -> 降采样
  -> 对 local_ivox 进行点面观测，得到更新后的 T_S_Ik
  -> 更新 local_ivox
  -> 保存不可变的 {stamp, T_S_Ik, P_k}
  -> 在 S 中拼接并降采样，必要时提交配准快照
```

帧内去畸变和帧间位姿补偿都要执行；只做其中一项不能得到运动一致的局部地图。

窗口按帧数、时间跨度、累计路程同时裁剪，避免局部漂移长期累积成内部形变。
起始实验值可设为最多 10 个选中帧、3 s、5 m 累计路程，实际值根据雷达频率与点数验证。
配准前还要检查有效点数、空间分布和局部跟踪是否正常，不能仅以达到 N 帧作为就绪条件。

配准线程只读取点云/位姿快照，不修改 ESKF 或活动地图；只保留最新待处理快照，避免排队积压。
局部 LIO 在配准期间继续跟踪和处理 IMU。

## 4. 与世界地图配准

粗配准统一使用 TEASER++，精配准使用 GICP。首版保留现有配置初值或 RViz
`/initialpose` 作为候选地图选择和可选几何提示，完整链路为：

```text
运动补偿得到 M_S
  -> 选择 W 系候选地图并降采样
  -> 两侧法向量和 FPFH 特征
  -> 互选、距离比筛选、唯一性和空间分布检查
  -> TEASER++ 粗配准，求 T_W_S_coarse
  -> 粗内点数、比例和残差 RMSE 检查
  -> GICP 精配准，输出完整 T_W_S
  -> 独立质量检查
```

移除重定位初始化中的普通 ICP，复用现有 `coarseRegister()` 的 FPFH/TEASER++
实现，以及 `refineRegister()` 的 GICP 和独立质量检查。TEASER++ 本身接收的是
对应点对，不能把两片无对应关系的原始点云直接送入求解器。

固定尺度为 1，不估计缩放；沿用现有 GNC_TLS 旋转估计与有界对应点数量。
粗配准必须通过对应点数量/空间分布、有效刚体变换、粗内点数/比例和内点 RMSE 检查，
再将完整粗变换作为 GICP 初值。对应点不足或退化时刷新局部窗口/候选地图后重试，
不以单位变换代替失败结果。

有先验时先对 W 地图做邻域裁剪，避免每次对整幅大地图提取和匹配 FPFH。
地图侧特征可按固定分块预计算并缓存，局部源点云特征按快照计算。

若初值是窗口中第 K 帧的世界位姿 `T_W_IK_prior`，源点云仍在 S 中，
换算为 S 到 W 的几何提示应是：

```text
T_W_S_hint = T_W_IK_prior * inverse(T_S_IK)
```

先验必须与保存的 `T_S_IK` 对应同一时刻。RViz 未明确关联扫描时间时，
需记录接收时对应的当前扫描与局部位姿；不能直接把当前机体世界位姿当作 S 的世界位姿。
位姿输入的 frame_id 要校验或转换，不再硬编码 z=0.2 m。

TEASER++ 不依赖这个提示进行迭代初始化；提示用于缩小 FPFH 对应点搜索范围。
带提示的配准未通过时，可在同一候选地图上重试无提示对应点匹配，仍须通过全部质量门限。
取消提示不能恢复已被裁剪掉的地图区域；先验偏差过大时应扩大地图候选范围或切换其他候选。

GICP 的最终变换已经包含 TEASER++ 粗配准初值，不再重复左乘粗变换。

若要求完全未知位置的自动全局重定位，需要另加世界地图分块和描述子索引，
先检索候选区域，再对每个候选执行同一条 FPFH -> TEASER++ -> GICP 链路。
TEASER++ 根据给定对应点估计变换，不自动完成大地图中的地点检索。
重定位候选不套用在线回环的“历史关键帧时间差 >30 s”门限；先验地图裁剪半径单独配置。

### 粗配准接受条件

对应点必须唯一且空间分布充分，拒绝近共线或过于集中的点对。
起始参数可参考现有实现：最少 6 对对应点、最多 200 对、最少 6 个粗内点、
粗内点比例至少 0.3、粗内点 RMSE 不超过 0.3 m。
这些是独立的粗配准实验参数，需在运动重定位数据上标定，不与 GICP 的 0.1 m² 门限混用。

### 精配准接受条件

继承用户已确认的门限：

- 独立最近邻内点 MSE 严格小于 0.1 m²。
- 源累积子图覆盖率严格大于 80%。
- 当前帧覆盖率严格大于 80%，防止历史累积部分对齐而当前帧没有对齐。
- 保留最少内点、收敛、有效刚体变换和几何退化检查。
- 配准结果须与可用的重力方向、先验搜索范围一致；相关容差独立配置。

为复用 `refineRegister(source, target, current, ...)`，三个输入必须是：

```text
source  = M_S
target  = M_W 或其 W 系裁剪地图
current = T_S_IK * P_K
```

`current` 必须先变到 S，不能把仍在 I_K 中的点云直接传入。
重定位的粗配准允许搜索更大的绝对位移，不能将回环的小修正范围误用为全局搜索范围。
GICP 相对粗配准初值的精修限制可以保留，并独立配置。

## 5. 配准成功后提交最新状态

工作线程返回 `{session_id, map_version, snapshot_stamp, T_W_S, quality}`。
只有主处理线程可以在扫描完成后的安全边界提交；提交前检查会话、地图版本、变换有效性
和当前局部跟踪状态。更换先验、地图或 S 会话时增加代号，丢弃旧任务结果。

假设快照在 K 帧发起，结果回来时已跟踪到 L 帧，应执行：

```text
T_W_IL = T_W_S * T_S_IL
```

不要把滤波器回退到 K 帧，也不要把当前时间改成配准快照时间或 -1。
由于 S 是固定坐标系，窗口更新和继续运动不会改变同一会话中的 T_W_S 含义。

令 `T_W_S = [A, t]`，转换当前完整滤波器状态：

```text
R_WI = A * R_SI
p_WI = A * p_SI + t
v_WI = A * v_SI
g_W  = A * g_S
bg_W = bg_S
ba_W = ba_S
```

偏置在 IMU/机体系中表达，因此不旋转。时间、原始 IMU 样本和标定参数保持连续。
全球加速度缓存也旋转；机体系角速度不变。

### 协方差和接口

当前 ESKF 状态顺序为 `[δθ, δp, δv, δbg, δba, δg]`，共 18 维，
旋转按 `R <- R * Exp(δθ)` 右乘更新，位置/速度/重力误差采用参考系中的加性表示。
对于确定的参考系变换：

```text
J = diag(I3, A, A, I3, I3, A)
P_W = J * P_S * transpose(J)
```

必须连同交叉协方差一起转换，不能只旋转位置协方差块或把整个 P 重置为小单位阵。
该式只描述坐标变换，未包含 T_reg 本身的不确定性；配准不确定性需保守膨胀或后续一致融合，
不能直接把 GICP 残差当成经过标定的位姿协方差。

建议新增专用接口：

```cpp
void ESKF::ChangeReferenceFrame(const BASIC::SE3& T_new_old);
```

该接口同时处理 R/p/v/g、P、前向预测的 fw_R/fw_p/fw_v、全球加速度缓存，清理残余 dx。
保持 IMU/观测时间及原始 IMU 历史的连续性。
现有 `SetX()` 不更新 g/P，又会改变 IMU 时间；`SetInitialConditions()` 会重设 P，
这两个接口都不能单独承担本次参考系切换。

## 6. 地图、缓存和输出同时切换

在同一安全边界完成：

1. 对最新 ESKF 执行参考系变换。
2. 活动点面地图从 `local_ivox` 切换为预先准备的 `reference_ivox`。
3. 更新或失效化 `sys_init_pose_`、`last_pose_`、世界点云缓存、传播历史等依赖 S 的数据。
4. 清理待处理局部配准任务和累积窗口，进入 WORLD_MAP_TRACKING。
5. 随后的每个扫描直接在 W 地图中进行 ESKF 观测；默认不修改参考地图。

不要把 S 地图原样并入 W 地图；若要增量扩图，另行启用并将点云按 W 位姿插入。
重定位成功的帧只发布一次与 W 一致的结果，避免一半数据仍在 S、一半已在 W。

ROSWrapper 当前将输出 frame_id 硬编码为 world，需要增加明确的参考系输出接口。
建议 TF 自始至终使用 `world -> odom_local -> imu`：

- 未定位时只发布 `odom_local -> imu`，不发布假定为单位阵的 world 连接。
- 成功后发布 `world -> odom_local = T_W_S`。
- ESKF 内部已切换到 W；此后 `odom_local -> imu` 由 `inverse(T_W_S) * T_W_I` 得到。
- 世界里程计和世界点云使用 W；禁止另一个发布器同时广播 world -> imu，造成同一子节点双父级。

初始化前不将 S 系关键帧作为 world 系关键帧发送给 SLAM 后端。

## 7. 建议代码改动

| 文件/模块 | 修改内容 |
| --- | --- |
| `src/lio/super_lio_reloc.cpp`、对应头文件 | 重定位状态机、双地图、局部跟踪、帧边界提交，删除初始化裸拼 |
| `src/lio/ESKF.cpp`、对应头文件 | 参考系转换接口与协方差/预测缓存处理 |
| 局部种子地图初始化 | 首帧建图；后续立即走逐帧预测、去畸变和观测，避免重复裸拼 |
| 新增重定位累积窗口 | 不可变帧点云、局部位姿、时间和路程裁剪 |
| 新增重定位配准任务管理 | 有界快照队列、FPFH/TEASER++/GICP、质量结果、会话版本检查 |
| `src/ros/ROSWrapper.cpp`、对应头文件 | 坐标标识/TF、定位状态、带时间关联的初值输入 |
| `launch/relocation.launch.py` 和配置 | 分离 sensor_config 与 relocation_config，加载地图/窗口/配准参数 |

重定位参数独立于在线回环参数；公共 FPFH/TEASER++/GICP 函数可复用，
但候选地图范围、粗配准参数和精配准接受门限由重定位配置明确提供。
构建重定位新路径需要 TEASER++ 依赖和 `SUPERLIO_WITH_TEASER=ON`；缺失时明确报错。
所有可重置状态放在对象成员中，不继续使用函数内 static 帧计数/已加载标志管理会话。

## 8. 验证与实施顺序

第一步：实现并验证局部 LIO 和运动补偿累积，先确认运动时墙面不出现重复层。
第二步：接入异步 FPFH/TEASER++/GICP 地图配准，验证 T_W_S 方向、先验提示换算与当前帧质量检查。
第三步：接入 ESKF 全状态切换、地图切换和 TF，再做完整回放。

必要测试：

- 已知平移/旋转轨迹下，多帧变到 S 后应重合；单帧本身需去畸变。
- 非单位雷达到 IMU 外参只应用一次。
- 非零 R/p/v/g/bg/ba 和含交叉项的 P，通过坐标变换后满足公式，往返变换可恢复。
- 配准延迟期间继续移动，提交时使用最新帧且时间不回退，IMU 样本不被重复积分。
- 首个 W 系预测/观测与切换前状态物理一致，局部点不误插进参考地图。
- MSE/覆盖率边界、错误初值、单平面退化、加载失败和配准失败重试。
- FPFH 对应点不足、粗内点不足、粗 RMSE 超限，以及带提示失败后无提示重试。
- 已知大平移/旋转下验证 TEASER++ 和 GICP 的完整变换方向，防止重复乘入粗变换。
- 新先验或地图版本使旧结果失效。
- TF 没有双父级，未定位输出不冒充世界位姿。
- 运动真实 bag 对比：局部地图形状、成功率、延迟、配准后的连续轨迹；有真值时再评价绝对误差。

验收重点是运动补偿后累积正确、配准方向正确、完整状态切换连续；单独出现“配准收敛”不足以证明方案成立。
